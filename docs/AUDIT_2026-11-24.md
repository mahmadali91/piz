## Функциональные проверки

- Вход/выход, CSRF-токены, восстановление пароля.
- Дашборд: фильтры, даты в модальном окне, сохранение вида
  «График/Линии/Таблица/Список» при смене периода.
- Касса: добавление товара, количество, удаление, 2/3/4 колонки.
- PDF и CSV: отчёт, смена, чек — отдаются с корректным `Content-Type`.

## Безопасность

### Исправлено

- **Подмена Host в ссылке письма.** Ссылка восстановления пароля
  строилась из `HTTP_HOST`. Теперь используется настройка `site_url`
  с фиксированным доменом.
- **Системные данные для кассира.** На `/settings` кассир видел версии
  PHP/MySQL и состояние БД. Блок «Система» теперь только для
  `settings.manage`.
- **Неверный статус CSRF.** Защита срабатывала, но отдавала 500.
  Теперь корректный 403.

### Проверено

- Пароли: `password_hash`/`password_verify`, bcrypt.
- Сессия: `Secure`, `HttpOnly`, `SameSite=Lax`, регенерация ID при входе.
- CSRF: проверка на всех POST, некорректный токен → 403.
- SQL: запросы с параметрами; динамический WHERE из фиксированных условий.
- XSS: вывод через `e()`, JSON в атрибутах экранируется, JS-вставки
  используют `textContent`/`esc()`.
- Загрузка фото: проверка `getimagesize`, перекодирование в JPEG,
  случайное имя, лимит 6 МБ.
- Открытый редирект: разрешены только пути, начинающиеся с `/` и не `//`.
- Заголовки: CSP, HSTS, `X-Frame-Options`, `nosniff`,
  `Referrer-Policy`, `Permissions-Policy`.
- Закрыты: `config/`, `storage/`, `archive/`, `temp/`, `tools/`,
  `data/`, `.git`, `piz_deploy_key2`.
- `VERSION` публично отдаёт только номер версии.

### Остаточные риски

1. **Письмо с новым паролем в открытом виде** — сделано по требованию
   пользователя. Рекомендуется отправлять одноразовую ссылку, а не пароль.
2. **Явное сообщение «аккаунт не найден»** — удобно, но позволяет
   проверять наличие email. Сделано осознанно.
3. **Нет 2FA** для администратора.
4. **Смена пароля не завершает другие активные сессии.**
5. **CSP разрешает inline-скрипты** из-за встроенных сценариев;
   риск XSS снижен экранированием, но nonce был бы строже.
6. **Нет DMARC** для домена; SPF настроен. Возможна подделка писем.
7. **Сброс пароля ограничен сессией**, не по IP/email — возможен
   подбор через новые сессии (низкая вероятность).
