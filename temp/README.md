# Временные файлы PIZZA

Сюда складываются временные скрипты, тестовые выгрузки, отладочные файлы и промежуточные данные.

Правила:

- всё временное — только внутри `PIZZA/temp/`, не в соседних папках и не в `/tmp`;
- секреты (`info.txt`, `config/config.php`, SSH-ключи) сюда не копировать;
- временные файлы не коммитятся;
- после завершения задачи папку можно очистить, `README.md` оставить.
