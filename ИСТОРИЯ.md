### Ответ

```bash
git clone https://github.com/mahmadali91/piz.git public_html
cd public_html
mkdir -p uploads/products storage/logs
chmod -R 775 uploads storage config
ls -la | head -20
```

Затем — открыть `http://piz.itop7.ru/setup`, ввести базу (`localhost`, `3306`, `mahmadgv_piz`, пароль из `info.txt`), создать администратора и оформить приход.

Отдельно указано, что HTTPS не работает и его нужно включить через Let's Encrypt.

## 3. Готово

> готова

### Ответ

Проверено снаружи:

- `http://piz.itop7.ru/healthz` → `{"ok":true}` — PHP и база подключены.
- `/setup` перенаправляет на `/login` — администратор создан, установка закрыта.
- `/login` открывается, стили и скрипты загружаются, версия на сервере — последняя.
- Служебные файлы закрыты: `config/config.php`, `src/`, `docs/`, `info.txt` — 403; API без входа — 401; cookie `HttpOnly` + `SameSite`; CSP и защитные заголовки на месте.
- Товары из Excel должны быть в базе: 35 позиций, остатки 0 — их нужно оприходовать.

Осталось включить HTTPS:

1. Панель Beget → **Сайты** → `piz.itop7.ru` → **SSL-сертификаты**.
2. Выпустить бесплатный **Let's Encrypt**.
3. Включить перенаправление HTTP → HTTPS.
4. Войти заново (cookie станут `Secure`) и сменить пароль, если он вводился по HTTP.
5. Проверить: дашборд (35 позиций), приход, тестовая продажа, печать, отмена.

## 5. HTTPS, прямой доступ и массовые операции

> Запрос на https отправил жду обновление
>
> - теперь создавай АПИ подключение к нашему проекту или любой способ чтоюы напрямю ты мог внести правки на нашем проекте и тестирвоать
> - например нужно всем товаров установит остаток по 100шт и всем товарам загрузить и генерировать фото миниатиюру

### Ответ

HTTPS ещё не поднят: `https://piz.itop7.ru` не отвечает (порт 443 закрыт), HTTP работает.

Для прямого доступа сгенерирован SSH-ключ и добавлен CLI-инструмент `tools/maintenance.php`:

- `stock:all 100` — массово устанавливает остаток 100 с записью движений склада;
- `photos:generate --all` — рисует квадратные миниатюры с названием, категорией и ценой, сохраняет в `uploads/products` и обновляет товары;
- `user:temp` / `user:delete` — временный администратор для проверки сайта;
- `stats` — сводка по товарам, фото, остаткам и продажам.

Публичный SSH-ключ передан в чате. После добавления в `~/.ssh/authorized_keys` на сервере можно подключаться напрямую, делать бэкап, массовые операции и тестировать сайт.
