# Проверки

Сквозные сценарии проверялись локально на PHP 8.5 + MySQL 8.0:

- установка и создание администратора;
- импорт `.xlsx` и `.csv`, фото товара;
- приход, инвентаризация, архив;
- продажи наличными, картой и переводом, скидка, сдача, отмена и возврат остатка;
- защита от повторной отправки чека (idempotency token);
- ограничения прав кассира и защита последнего администратора;
- CSRF, XSS, ограничение попыток входа;
- экспорт CSV и печать чека/отчёта.

Быстрая проверка синтаксиса:

```bash
find . -path ./.git -prune -o -name '*.php' -print0 | xargs -0 -n1 php -l
```

Проверка сервиса на хостинге: `GET /healthz` и раздел «Настройки → Система».
