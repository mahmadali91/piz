# AGENTS.md — PIZZA / КИОСК ДОНЕР

## Главное правило

Не перечитывать всю историю проекта и не повторять проверки без необходимости.
Для обычной задачи достаточно `PROJECT_BRIEF.md` и текущего запроса.

## Что не делать каждый раз

- Не читать `ИСТОРИЯ.md`, `archive/`, `README.md`, `ИНСТРУКЦИЯ.md` целиком, если задача не про документацию.
- Не делать скриншоты и `read_image`, если интерфейс не менялся. Максимум 1–2 изображения на релиз.
- Не запускать полный smoke-тест всех страниц после каждой мелкой правки. Один финальный прогон.
- Не проверять `/healthz`, `stats`, PWA installability и все 35 картинок после каждого изменения. Только в конце релиза.
- Не переписывать README/ИНСТРУКЦИЮ/ИСТОРИЮ/архив на каждую правку. Добавлять короткую запись в changelog.
- Не обновлять версию, тег, ZIP и Git bundle для каждой мелочи. Только по запросу релиза или для значимого изменения.
- Не вызывать `web_search` повторно по тем же товарам/вопросам. Источники сохранять в `docs/`.
- Не выводить полные файлы и длинные логи. Использовать `grep`, `read` с offset/limit, точечные команды.
- Не запускать фоновые задания без реальной необходимости.
- Не пересказывать в финальном ответе всю предыдущую работу. Только результат, проверка, ссылки.

## Как работать с новой задачей

1. Прочитать `PROJECT_BRIEF.md` (1 страница).
2. Сделать только запрошенное.
3. Проверить минимально достаточным способом.
4. Обновить документацию только если изменилось поведение.
5. Закоммитить и дать короткий отчёт.

## Если задача большая

Начать **новую сессию** и приложить `PROJECT_BRIEF.md`.
Не тянуть в новый чат старую переписку, скриншоты и логи.
