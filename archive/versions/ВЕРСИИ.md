## Восстановление версии из bundle

```bash
git clone archive/versions/piz-full-history.bundle PIZZA-restored
cd PIZZA-restored
git tag -l
git checkout v1.0.0-pwa
# или
git checkout v1.0.0-doner
```

Теги `v1.23.26`, `v1.24.26-2` … `v1.24.26-36` находятся в основном репозитории GitHub и локальном `.git` — они созданы после снимка bundle. Для последней версии используйте текущий репозиторий `PIZZA`.
