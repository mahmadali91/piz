# Версии проекта

Текущая версия: **v1.24.26**. История Git: `piz-full-history.bundle` (снимок) + теги в `.git`.
Текущая сборка: `../../dist/piz-kiosk-v1.24.26.zip`.

| Версия | Что вошло |
|---|---|
| `v1.0.0-pwa` | Мобильная PWA: манифест, service worker, установка на телефон, офлайн-страница, карточки товаров и продаж |
| `v1.0.0-doner` | КИОСК ДОНЕР: склад из пяти вкладок, приход партиями, расход, отрицательные остатки, массовые цены, смены с отчётом и CSV, права на цены/склад, переименование |
| `v1.23.26` | Версия сайта в блоке администратора, `VERSION`, `VERSION.md` |
| `v1.24.26` | **Текущая версия:** отдельные меню «Товары и остаток», «Приход», «Расход»; массовые цены через ползунок; история цен в карточке товара |

## Восстановление версии из bundle

```bash
git clone archive/versions/piz-full-history.bundle PIZZA-restored
cd PIZZA-restored
git tag -l
git checkout v1.0.0-pwa
# или
git checkout v1.0.0-doner
```

Теги `v1.23.26` и `v1.24.26` находятся в основном репозитории GitHub и локальном `.git` — они созданы после снимка bundle. Для последней версии используйте текущий репозиторий `PIZZA`.
