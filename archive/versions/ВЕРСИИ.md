# Версии проекта

Полная история Git: `piz-full-history.bundle`.
Текущая сборка: `../../dist/piz-kiosk-1.0.0.zip`.

| Версия | Что вошло |
|---|---|
| `v1.0.0-pwa` | Мобильная PWA: манифест, service worker, установка на телефон, офлайн-страница, карточки товаров и продаж |
| `v1.0.0-doner` | КИОСК ДОНЕР: склад из пяти вкладок, приход партиями, расход, отрицательные остатки, массовые цены, смены с отчётом и CSV, права на цены/склад, переименование |

## Восстановление версии из bundle

```bash
git clone archive/versions/piz-full-history.bundle PIZZA-restored
cd PIZZA-restored
git tag -l
git checkout v1.0.0-pwa
# или
git checkout v1.0.0-doner
```
