# Версии проекта

Текущая версия: **v1.24.26-7**. История Git: `piz-full-history.bundle` (снимок) + теги в `.git`.
Текущая сборка: `../../dist/piz-kiosk-v1.24.26-7.zip`.

| Версия | Что вошло |
|---|---|
| `v1.0.0-pwa` | Мобильная PWA: манифест, service worker, установка на телефон, офлайн-страница, карточки товаров и продаж |
| `v1.0.0-doner` | КИОСК ДОНЕР: склад из пяти вкладок, приход партиями, расход, отрицательные остатки, массовые цены, смены с отчётом и CSV, права на цены/склад, переименование |
| `v1.23.26` | Версия сайта в блоке администратора, `VERSION`, `VERSION.md` |
| `v1.24.26` | Отдельные меню «Товары и остаток», «Приход», «Расход»; массовые цены через ползунок; история цен в карточке товара |
| `v1.24.26-2` | Цветные иллюстрации для всех 35 товаров |
| `v1.24.26-3` | Поставщики и накладные, инвентаризация, PDF |
| `v1.24.26-4` | Убраны кнопки печати, история смен внизу |
| `v1.24.26-5` | Сворачиваемое боковое меню |
| `v1.24.26-6` | Приход и расход несколькими товарами |
| `v1.24.26-7` | **Текущая версия:** ветка «Ещё» и меню администратора |

## Восстановление версии из bundle

```bash
git clone archive/versions/piz-full-history.bundle PIZZA-restored
cd PIZZA-restored
git tag -l
git checkout v1.0.0-pwa
# или
git checkout v1.0.0-doner
```

Теги `v1.23.26`, `v1.24.26-2` … `v1.24.26-7` находятся в основном репозитории GitHub и локальном `.git` — они созданы после снимка bundle. Для последней версии используйте текущий репозиторий `PIZZA`.
