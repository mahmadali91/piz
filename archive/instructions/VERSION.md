# Версия сайта

**Текущая версия: `v1.24.26-18`**

Версия хранится в файле [`VERSION`](VERSION) — одна строка без префикса `v`.

## Формат

```
v1.24.26-18
│ │  └── год: 2026 → 26
│ └───── день: 24
└─────── поколение / major: 1
```

- `1` — поколение сайта;
- `24` — день месяца;
- `26` — год (2026);
- `-18` — восемнадцатая правка за день.

Если в один день выходит несколько изменений, добавляется номер правки:

```
v1.24.26-2
v1.24.26-3
```

## Где отображается

- в блоке пользователя слева, под ролью: **«Версия v1.24.26-18»**;
- в **Настройках → Система**: «Версия сайта»;
- в футере страницы входа;
- в `/healthz` (JSON, поле `version`);
- в HTML: `<meta name="app-version" content="v1.24.26-18">`.

## Как выпустить новую версию

1. Измените число в файле `VERSION`:

   ```bash
   printf '1.25.26\n' > VERSION
   ```

2. Обновите дату/описание в этом файле.
3. Проверьте отображение в блоке администратора и в настройках.
4. Пересоберите локальный ZIP:

   ```bash
   git archive --format=zip --output=dist/piz-kiosk-v1.25.26.zip HEAD
   ```

5. Закоммитьте `VERSION` и `VERSION.md`.
